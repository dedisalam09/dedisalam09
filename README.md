### 🎯 5 Pilar Tugas Utama
1. **Fluiditas UI 60 FPS & Isolate Offloading:** Memisahkan komputasi berat (JSON parsing, kriptografi) ke background isolates terpisah agar UI thread tetap mulus pada 60 FPS tanpa jank atau frame drops.
2. **Sound-Typed Dart Data Models (0% Dynamic):** Menegakkan sistem tipe statis ketat tanpa penggunaan tipe dynamic, menjamin deserialisasi model API aman dari runtime TypeError.
3. **Hardware-Backed Keystore & Security:** Menyimpan token dan data sensitif secara aman menggunakan flutter_secure_storage (Android KeyStore & iOS Keychain) serta mengaktifkan SSL/TLS certificate pinning.
4. **Idempotent Offline-First Sync Queue:** Membangun antrean mutasi data offline berbasis SQLite/Hive lokal yang disinkronkan secara idempotens saat konektivitas kembali pulih.
5. **Ergonomi Sentuh & Adaptive Layouts:** Menjamin seluruh target sentuh interaktif memenuhi standar ergonomi minimal 48x48 dp serta adaptif terhadap SafeArea di seluruh variasi form factor perangkat.
